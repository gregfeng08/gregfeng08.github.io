# Media for "Canvas RAG Teaching Assistant"

Drop image and video files in THIS folder and they appear in this project's
figure carousel automatically (while `npm run dev` runs, or after `npm run build`).

- Order = filename order, so prefix files with `01-`, `02-`, `03-`...
- Video: `.mp4` / `.webm` / `.mov` / `.m4v` (renders with player controls)
- Images: `.jpg` / `.png` / `.webp` / `.gif` / `.svg`
- One file shows with no dots; multiple files get dot + arrow navigation.

This README is ignored (only image/video files are picked up). You can delete it.
